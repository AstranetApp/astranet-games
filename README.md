# Astranet Games

Мини-игры для вкладок сообщества [Astranet](https://astranetapp.com) и
референсная реализация интеграции с Astranet Web Tab SDK.

Игры публикуются целиком: клиент, сервер, схема базы данных, серверная
валидация результатов и турнирные таблицы. Каждая игра остаётся обычным
веб-приложением и вне Astranet работает в гостевом режиме.

| Игра | Описание | Прод |
| --- | --- | --- |
| [ЖК «Щастливый Гой»](games/happy-goi) | Визуальная новелла с двумя мини-играми: сапёр и пункт пропуска | [goi.astranetapp.com](https://goi.astranetapp.com) |

## Интеграция с Astranet

Протокол идентификации описан в [`docs/web-tab-sdk.md`](docs/web-tab-sdk.md):
формат запроса и ответа, транспорт для веба и мобильных клиентов, требования
к обработке токена. Реализация занимает около 60 строк и не требует
зависимостей.

## Технические решения

Разделы ниже описывают подходы, применённые в играх репозитория. Каждый
разобран в коде с комментариями, объясняющими мотивацию решения.

### Идентификация игрока

Astranet выдаёт анонимный pairwise-токен: один и тот же игрок получает
одинаковый идентификатор в веб-клиенте и в мобильном приложении, при этом
аккаунт не раскрывается. Токен является bearer-идентификатором, поэтому
в базу данных он не записывается — сохраняется только
`sha256(salt + значение)`, усечённый до 32 символов.

Реализация: [`sdk.ts`](games/happy-goi/client/src/astranet/sdk.ts),
`parseAuth()` в [`server.js`](games/happy-goi/server/server.js).

### Начисление очков на сервере

Клиент не участвует в подсчёте результата. Партия регистрируется до начала
(`POST /api/game/start`) и получает сид от сервера; по завершении клиент
передаёт только исход и длительность, очки вычисляет сервер по собственной
формуле. Единственный подделываемый параметр — время, и оно проверяется
по фактическому времени жизни партии и по нижнему порогу правдоподобия:

```js
const plausible = duration >= d.minTime && duration <= elapsed + 3;
```

Пороги (`minTime` — 0.8 / 4 / 12 с) заведомо ниже мировых рекордов: задача
проверки — отсечь физически невозможные результаты, не отклоняя результаты
быстрых игроков. Полная защита клиентской логики в браузере недостижима;
цель — сделать подлог дороже честной игры и сохранить корректность
турнирной таблицы.

Реализация: `POST /api/game/finish`, `POST /api/shift/finish`
в [`server.js`](games/happy-goi/server/server.js).

### Детерминированная генерация

Сид выдаёт сервер, поле и очередь строятся детерминированным ГПСЧ
(mulberry32). Повторная загрузка страницы не изменяет расклад, а результаты
разных игроков остаются сопоставимыми.

Реализация: [`minesweeper.ts`](games/happy-goi/client/src/game/minesweeper.ts),
[`checkpoint.ts`](games/happy-goi/client/src/game/checkpoint.ts).

### Гостевой режим

Вне Astranet игра полностью функциональна: идентификатор генерируется как UUID
в `localStorage`, весь контент доступен, прогресс сохраняется локально.
Тот же режим используется при локальной разработке, поэтому его
работоспособность проверяется постоянно.

### Сервер без внешних зависимостей

Сервер реализован на Node.js ≥ 22.5 средствами `node:http` и `node:sqlite`,
без npm-пакетов: раздача статики с поддержкой Range-запросов, REST API,
турнирные таблицы, ограничение частоты запросов. Это сокращает поверхность
атаки и снимает необходимость регулярного обновления зависимостей.

### Механики удержания

Серии побед с ограниченным множителем, зачёты за день, ISO-неделю и всё время
по лучшему результату каждого игрока, а также расчёт недостающих до топ-10
очков после партии. Механики принудительного удержания (таймеры ожидания,
расходуемая энергия, внутриигровые покупки) не используются.

## Требования и запуск

Node.js ≥ 22.5. В версиях 22.x модуль `node:sqlite` требует флага
`--experimental-sqlite`; в Node.js 24 он доступен без флага.

```bash
cd games/happy-goi/client
npm ci
npm run build

cd ..
DATA_DIR=/tmp/goi PORT=8097 node --experimental-sqlite server/server.js
```

Сервер раздаёт собранный клиент и обслуживает API на одном порту.
Для развёртывания в каждой игре есть `Dockerfile`:

```bash
docker build -t happygoi games/happy-goi
docker run -d --name happygoi --restart unless-stopped \
  -p 127.0.0.1:8097:8097 -v happygoi-data:/data happygoi
```

## Аудиофайлы

Саундтрек ЖК «Щастливый Гой» состоит из произведений сторонних авторов
(AZALI, XEOLT), права на распространение которых у нас отсутствуют. Файлы
`.mp3` в репозиторий не включены.

Игра работоспособна без них: аудиоплеер штатно обрабатывает недоступность
файлов. Перечень треков, требования к именованию и параметры нормализации
приведены в
[`client/public/audio/README.md`](games/happy-goi/client/public/audio/README.md).
