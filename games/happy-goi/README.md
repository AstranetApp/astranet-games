# ЖК «Щастливый Гой»

Визуальная новелла с мини-играми для вкладки сообщества Astranet. Игрок
заселяется в ЖК, знакомится с консьержами — Мару и Святой Булочкой, —
разминирует двор после очередной выходки Чаки и дежурит на пункте пропуска
у Ell Mersenz.

**Прод:** https://goi.astranetapp.com

## Что внутри

| Часть | Где |
| --- | --- |
| Astranet Web Tab SDK: identity-токен (iframe + native WebView, таймаут, гостевой фолбэк) | `client/src/astranet/sdk.ts` |
| Токен — bearer: не в URL, не в UI, на сервере только `sha256(salt+token)` | `sdk.ts`, `server/server.js` |
| Движок новеллы: сцены, спрайты, посимвольный вывод | `client/src/vn/` |
| Сценарий целиком (пролог, брифинг, реакции) | `client/src/vn/script.ts` |
| Сапёр: чистое иммутабельное ядро | `client/src/game/minesweeper.ts` |
| Пункт пропуска: правила, генерация очереди, проверка решений | `client/src/game/checkpoint.ts` |
| API + турнирные таблицы | `server/server.js` |

Клиент — React 19 + Vite + TypeScript. Сервер — Node ≥ 22.5 на `node:http` и
`node:sqlite`, **ноль npm-зависимостей**; он же раздаёт собранную статику.

## Сюжет и персонажи

Пролог начинается на затемнённой вечерней улице старого района и заканчивается
во дворе ЖК; показывается он один раз — флаг `seenIntro` живёт на сервере,
поэтому у одного и того же игрока Astranet знакомство не повторится ни в вебе,
ни в приложении. Номер квартиры детерминирован по игроку: Мару «подбирает» его
в прологе, и он остаётся тем же на всех устройствах.

- **Мару** — консьерж, мягкий и вечно недоспавший, говорит с «>~<».
- **Святая Булочка** — второй консьерж, отвечает за порядок и за то, чтобы
  никто не взлетел на воздух.
- **Ell Mersenz** — жилец четвёртого подъезда, самоназначенный президент
  шлагбаума. Депортирует всё, что не нравится, включая арендную плату.
- **Чэстер** — медик ЖК, собирает подорвавшихся обратно. **Ник** — жилец с
  третьего этажа, которому взрывы удобно открывают окно и остужают чай.
- **Чаки** — жилица третьего подъезда. Платит вовремя, здоровается,
  придерживает дверь. Просто ей бывает скучно, и тогда во дворе появляются
  мины.

Добавить персонажей и реплики можно, не трогая код: спрайты описываются в
`vn/types.ts`, сцены — массивы шагов в `vn/script.ts`. Шаг умеет менять фон,
уровень затемнения (`dim`), состав сцены и эффект; в текстах доступны
подстановки `{name}` и `{flat}`.

Спрайты обрезаны по бёдра, поэтому в сцене они «стоят» на нижнем крае экрана,
а срез уходит под рамку реплики и мягко растворяется маской — обрубленных ног
не видно.

## Музыка и настройки

| Экран | Трек |
| --- | --- |
| пролог, главное меню, таблица | AZALI — seaside hometown |
| брифинг Булочки, поле, итог партии | AZALI — field of mirrors (small enemy encounter) |
| смена на пункте пропуска | XEOLT — Overclock Resurgence |

Самих файлов в репозитории нет — треки чужие; игра работает и без них, а как
вернуть звук или поставить свой, написано в
[`client/public/audio/README.md`](client/public/audio/README.md).

Трек меняется кроссфейдом и только тогда, когда персонажи договорили: брифинги
идут ещё под спокойную тему, иначе смена музыки перебивает реплику на полуслове.
Реализация — `client/src/audio/music.ts`. Браузеры и WebView
запрещают автовоспроизведение до первого жеста, поэтому отклонённый `play()`
не считается ошибкой: желаемый трек запоминается и стартует на первом клике
или нажатии клавиши. Название играющего трека висит в правом нижнем углу —
на поле сапёра постоянно, на остальных экранах пять секунд после смены,
чтобы не спорить с рамкой реплики. Там же кнопка быстрого отключения звука.

Исходники треков различались по громкости на 5–12 dB, поэтому при конвертации
все приведены к −23.5 dB: переключение между экранами не бьёт по ушам.

Настройки (кнопка в меню) — громкость музыки, выключение звука, громкость
голосов и скорость печати текста; хранятся в localStorage, потому что
относятся к устройству, а не к аккаунту.

### Голоса персонажей

`client/src/audio/voice.ts` — короткие «блипы» на печатающийся текст, как в
Undertale. Сэмплов нет: осциллятор с фильтром, поэтому голос — это семь чисел.
Мару звучит выше и с подъёмом тона (он вечно заигрывает), Булочка — ровный
квадрат пониже, Ell — гнусавая пила с падением (он вещает, а не разговаривает),
рассказчик — тихая синусоида. На пробелах и знаках препинания голос молчит,
чтобы речь звучала словами, а не ровным треском. Громкость подобрана так, чтобы
голоса были слышны поверх музыки на её обычной громкости: приглушать музыку
ради реплик — не выход.

## Мини-игра «сапёр»

Три сложности: **Подъезд** 9×9/10, **Секция** 16×16/40, **Весь ЖК** 30×16/99.

- первый клик всегда безопасен: мины раскладываются после него, минуя клетку
  и её соседей;
- расклад детерминирован сидом сервера — перезагрузка ради удобного поля
  бесполезна;
- аккорд (клик по цифре с нужным числом флажков), флажки правой кнопкой,
  долгим тапом или режимом флага в шапке; с клавиатуры — Tab + Enter, `F`;
- на телефоне плитка не мельче 26 px, большое поле прокручивается.

### Очки и серия побед

```
очки = (база сложности + бонус за скорость) × множитель серии
множитель = 1 + 0.12 × min(серия − 1, 10)     → до ×2.2
```

База: 1000 / 3000 / 7000. Бонус за скорость — за укладывание в «норматив»
(45 / 150 / 330 с). Серия растёт с каждой победой и сгорает от одного подрыва:
поражение не даёт очков вовсе.

Таблицы: день, ISO-неделя, всё время — по лучшему результату каждого игрока.
После партии сервер считает, сколько очков не хватило до топ-10 дня.

### Анти-чит

Партия регистрируется на сервере до начала (`/api/game/start`), **очки считает
сервер** — клиент присылает только исход и длительность. Подделать можно лишь
время, и оно проверяется по реальному времени жизни партии и по порогу
`minTime` (0.8 / 4 / 12 с — заведомо ниже мировых рекордов, чтобы честный
быстрый игрок не получил отказ). Партия одноразовая: повторный финиш — 409.

Если сервер всё же отклонил результат, игра честно пишет «очки не начислены»,
а не подменяет исход партии.

## Мини-игра «пункт пропуска»

Ell Mersenz самоназначился президентом шлагбаума и посадил игрока на контроль.
К будке по одному подходят объекты с пропусками: посылка, мина Чаки, кот,
пицца, тележка, лужа, счёт за ЖКХ, арендная плата, взрыв, декабрь, шум сверху,
нефтевышка и орёл. Решение одно из двух — **впустить** или **ДЕПОРТИРОВАТЬ**
(мышью или стрелками).

- смена длится 60 секунд, очередь — 55 посетителей; разобрать её досрочно
  выгодно: за оставшееся время идёт бонус;
- Ell выпускает указы по ходу смены, каждые 12 секунд добавляется новый —
  к концу их пять, и держать в голове нужно все;
- амнистия котов приходит последней и ломает привычку депортировать всё
  подряд;
- три ошибки закрывают смену досрочно и сжигают серию.

Набор указов подбирается под сид так, чтобы к концу смены депортаций было
около половины: случайный набор иногда вырождался в «жми депортацию не глядя»
(до 93% нарушителей), и решение переставало быть решением.

Бланк пропуска и пиктограммы объектов рисуются кодом — растровых ассетов у
мини-игры нет, кроме фона будки. Новый тип посетителя стоит десяти строк
в `client/src/game/checkpoint.ts`.

## Запуск

```bash
# клиент
cd client && npm install && npm run build

# сервер (Node 22.x требует флаг sqlite; в контейнере node:24 — не нужен)
DATA_DIR=/tmp/goi PORT=8097 node --experimental-sqlite server/server.js

# разработка клиента с горячей перезагрузкой (API проксируется на :8097)
cd client && npm run dev
```

Прод:

```bash
docker build -t happygoi .
docker run -d --name happygoi --restart unless-stopped \
  -p 127.0.0.1:8097:8097 -v happygoi-data:/data happygoi
```

## API

| Метод | Что делает |
| --- | --- |
| `POST /api/hello` | профиль: имя, квартира, серия, рекорды, места |
| `POST /api/intro/seen` | отметить пролог просмотренным |
| `POST /api/name` | имя жильца (2–16 символов, санитизация) |
| `POST /api/game/start` | регистрация партии → `gameId` + сид поля |
| `POST /api/game/finish` | исход + длительность → очки, серия, места, callout |
| `POST /api/shift/start` | регистрация смены на КПП → `shiftId` + сид очереди |
| `POST /api/shift/finish` | счётчики смены → очки, серия, места |
| `GET /api/leaderboard?board=daily\|weekly\|alltime` | топ-50 и своё место |

Авторизация — заголовок `X-Player: astra <token>` либо `X-Player: guest <uuid>`.

## Ассеты

Музыка — mp3 112 kbps в `client/public/audio/` (сервер отдаёт её с поддержкой
Range-запросов, иначе буферизация в некоторых WebView работает через раз).
В репозиторий аудио не входит, см.
[`client/public/audio/README.md`](client/public/audio/README.md).

Графические исходники лежат в `assets_src/`, в сборку идут webp из `client/public/assets/`:
двор ЖК (2.5 МБ png → 294 КБ webp), вечерняя улица для пролога (2.7 МБ → 320 КБ),
спрайты Мару и Булочки (у Булочки белый фон вырезан заливкой от углов). Шрифты
Comfortaa и Nunito — self-hosted сабсеты latin + cyrillic, внешних запросов игра
не делает.
