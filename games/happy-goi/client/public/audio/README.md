# Саундтрек

Аудиофайлы в репозиторий не включены: композиции написаны сторонними
авторами, права на их распространение отсутствуют.

Игра работоспособна без аудиофайлов. Плеер
([`music.ts`](../../src/audio/music.ts)) штатно обрабатывает недоступность
источника: отклонённый вызов `play()` не считается ошибкой — этот же механизм
используется для обхода запрета автовоспроизведения до первого действия
пользователя.

## Состав саундтрека

| Имя файла | Композиция | Экраны |
| --- | --- | --- |
| `seaside-hometown.mp3` | AZALI — seaside hometown | пролог, главное меню, таблица результатов |
| `field-of-mirrors.mp3` | AZALI — field of mirrors (small enemy encounter) | брифинг, поле сапёра, итог партии |
| `overclock-resurgence.mp3` | XEOLT — Overclock Resurgence | смена на пункте пропуска |

Соответствие композиций экранам задаётся структурой `TRACKS`
в [`music.ts`](../../src/audio/music.ts); имена файлов в других модулях
не используются.

## Подключение собственных композиций

Поместите три файла с указанными именами в этот каталог либо измените
`TRACKS` в [`music.ts`](../../src/audio/music.ts).

Перед сборкой приведите композиции к единому уровню громкости. Исходные
записи различаются между собой (в исходном наборе расхождение достигало
12 dB), что приводит к резким перепадам громкости при переключении экранов:

```bash
ffmpeg -i исходник.m4a -af loudnorm=I=-23.5:TP=-1.5:LRA=11 -b:a 112k seaside-hometown.mp3
```

Битрейт 112 kbps выбран как компромисс между качеством фоновой музыки
и объёмом загрузки в мобильных сетях.

Для точной подстройки отдельной композиции предусмотрено поле `gain`
в структуре `TRACKS`: его значение умножается на уровень громкости
из пользовательских настроек.

## Источники композиций со свободной лицензией

- [Incompetech](https://incompetech.com)
- [Free Music Archive](https://freemusicarchive.org) — с фильтром по CC0 и CC-BY
- [OpenGameArt](https://opengameart.org)

Условия атрибуции различаются в зависимости от лицензии; проверяйте их
перед публикацией проекта.

## Альтернативный подход

Аудиофайлы не являются обязательными: звуковое сопровождение может
синтезироваться средствами Web Audio API непосредственно в браузере.
В этом проекте так реализованы голоса персонажей —
см. [`voice.ts`](../../src/audio/voice.ts), где тембр каждого персонажа
задаётся семью числовыми параметрами осциллятора и фильтра.
