# Участие в разработке

## Требования к окружению

- Node.js ≥ 22.5 (рекомендуется 24: модуль `node:sqlite` доступен без флага)
- Для сборки клиента — npm

```bash
cd games/happy-goi/client
npm ci
npm run dev          # разработка, API проксируется на 127.0.0.1:8097
```

Одновременно запустите сервер, иначе запросы к API завершатся ошибкой
и приложение перейдёт на экран недоступности:

```bash
cd games/happy-goi
DATA_DIR=/tmp/goi PORT=8097 node --experimental-sqlite server/server.js
```

## Проверки перед отправкой изменений

```bash
cd games/happy-goi/client
npx tsc -b           # проверка типов
npm run build        # сборка должна проходить без ошибок
```

Те же проверки выполняются в CI при создании pull request.

## Требования к коду

**Серверная часть не использует npm-зависимости.** Сервер построен на
`node:http` и `node:sqlite`. Предложения, добавляющие внешние пакеты
на сервер, должны содержать обоснование: отсутствие зависимостей —
осознанное архитектурное решение, сокращающее поверхность атаки.

**Игровые правила и подсчёт результата остаются на сервере.** Клиент
передаёт исход и длительность, но не итоговый счёт. Изменения, переносящие
начисление очков на клиент, не принимаются.

**Дублирование констант документируется.** Параметры сложности заданы
одновременно в `client/src/game/difficulty.ts` и в `server/server.js`;
при изменении правьте оба места, в комментариях это отражено.

## Требования к комментариям

Репозиторий используется как справочный пример, поэтому к комментариям
предъявляются повышенные требования.

Комментарий объясняет причину решения, а не действие, выполняемое кодом:

```js
// Плохо: увеличиваем счётчик ошибок
// Хорошо: три ошибки закрывают смену досрочно — иначе выгодно жать
//         «депортировать» не глядя
```

- заголовок файла описывает зону ответственности модуля и его границы;
- пустой блок `catch` сопровождается объяснением, почему ошибка допустима;
- комментарии, дублирующие соседний код или расположенные не над относящимся
  к ним фрагментом, подлежат удалению.

## Художественные материалы

Изображения, шрифты и аудиофайлы не покрываются лицензией репозитория.
Не добавляйте материалы, права на распространение которых не подтверждены.
Аудиофайлы исключены из репозитория, см.
[`games/happy-goi/client/public/audio/README.md`](games/happy-goi/client/public/audio/README.md).

## Оформление изменений

- одно логическое изменение — один pull request;
- в описании укажите причину изменения, а не только его состав;
- при изменении игровых формул укажите, как это влияет на существующие
  записи в турнирных таблицах.
